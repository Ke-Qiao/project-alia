- 根文件系统约 117 GiB、可用约 104 GiB；单次温度 36.4℃。它们是盘点时的快照，不是负载或长期稳定性结果。
- `lsusb` 当前只有 USB root hubs，未识别 R1；内核列出两个 HDMI 音频设备。本用户对现有 `/dev/snd` 的 `root:audio`、0660 节点没有读写权限，所以 `arecord/aplay -l` 的无声卡提示不能解释成内核完全没有声卡。用户随后确认 R1 尚未接入，后续使用 USB，当前未枚举符合现状；不是接入后的识别故障。未更改组权限或打开 PCM 录放音；固件和格式仍待实际设备核对。
- `rustc/cargo/protoc` 在本次非交互 PATH 中未找到；进一步只读确认 `~/.cargo/bin` 已有 Rust shims，rustup 列出 active/default `stable-aarch64-unknown-linux-gnu`。这不是“Rust 未安装”；后续部署需固定实际版本及调用环境，`protoc` 可用性仍待解决。
- 存在 `/dev/i2c-1`、`/dev/i2c-13`、`/dev/i2c-14`，没有扫描总线或读写寄存器；节点存在不证明 PCA9685 板卡在线。没有 USB 串口稳定标识目录，不能据此推断 I²C 板卡缺失。

另提供[无设备 staging 模板](../../config/embedded.staging.example.toml)，用于未来独立目录中的生命周期验证：七个模块均 noop，所有设备与发现关闭，保留绑定门槛，监听 loopback 临时端口。**正常启动 staging 仍写 key/SQLite 并监听**；本轮只验证模板离线检查，没有启动它。通用 embedded.example.toml 不是 Pi 实际配置，更不是无设备模板。详见[部署步骤](server-embedded.md)。

## R02 首个交付包：声学链路与 AEC

复用 [native reference/clock 契约](../refactor/audio-reference-clock-design.md)和现有 post-mix reference。mixer 已经存在，生产软件 AEC consumer 尚不存在。用户已说明 R1 支持硬件 AEC，因此先核对所选阵列的实际工作模式、输出声道和播放参考要求，再决定是否需要软件 AEC、放置位置与依赖；不在未知硬件处理之后直接叠加另一个消回声处理器。

“支持硬件 AEC”不等于已开启，更不等于 Pi 的扬声器信号已进入阵列的回声参考路径。麦克风和扬声器位于同一 Pi 也不能证明参考已连接或采播共享时钟。当前 post-mix 软件参考只证明主机音频边界，不证明阵列已经消费它。参考路由、接线与配置需依据该型号资料和现场核对；扬声器/功放未选定前不固定电气接法或声学阈值。

已从 [亚博 R1 官方介绍](https://www.yahboom.com/build.html?id=16444&cid=743) 核对：UAC 采集输出与功放输出参考接口是不同路径，不能默认把 USB 播放当作 AEC 参考。具体版本、输入额定值与功放兼容性未确认；条件性扬声器/功放方案见 [audio HANDOFF](../refactor/handoffs/2026-10-14-hardware-confirmation/audio-HANDOFF.md)。

1. **R02-A 软件证据包已完成**，源码 `e557ceb`，见 [10/10 checklist](../refactor/checklists/r02-a-2026-10-14.md)。native capture 与最终 playback reference 的 boot/stream、continuity、sequence、lost counters、格式、游标、clock quality、可用 queue delay 与主机观察时间已纳入同一有界格式；采播仍各自独立时钟。旧 AudioDebugRecorder 已删除，默认没有自动证据会话或文件录音；运行采集时仍有固定大小的内存 PCM 队列。真实音频的保留位置、时长与删除规则需在采集前确定，本轮没有采集真实音频。
2. 独占 reader、有界导出与合成 PCM 离线重放已完成，macOS 默认 Embedded 回归284/0/0；本轮Linux/ALSA未运行。未来若采用软件 AEC，由同一音频 worker 安排参考消费，并在 wake/VAD/上传之前处理 capture；按选定 AEC 的要求重分帧，不能把现有 1024 样本参考块或上传帧当作 AEC 帧。若使用阵列硬件 AEC，则记录其实际处理输出与参考来源，不把软件旁路命名成软件 AEC。两种路径均须明确时钟域、参考缺口、xrun/重开与重新收敛；缺失参考不能补成“真实静音”。
3. 使用确认的设备和素材做单讲、双讲、附和、明确 WAIT/Continue、噪声、重连与尾音测量；保留样本量和失败分母、用户语音完整性、自唤醒/自转写、插话到实际停声时间、资源趋势。验收阈值在基线测量后明确，模型标签和服务耗时不能代替听感或停声证据。

设备尚未完成当前核验；已完成的有界记录格式、离线重放和回归不能代替现场核验，不把软件 reference 测试或 R1 型号说明勾选为 AEC 已完成。R03-A 软件现已完成，现场资料确认后再开展真实 R02/R03 验收。
