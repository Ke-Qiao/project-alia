# Project Alia 后续工作台账

更新：2026-09-20。关联：[首轮重构计划](plan.md)。

用途：记录暂时搁置的内容及恢复条件，供后续轮次继续执行。当前首轮范围为 macOS Server + Raspberry Pi 5 8 GB，语音目标为自然全双工，基线为 `3530395`。

状态必须区分：**用户明确延期**、**随前端延期的产品集成**、**待技术门槛的首轮候选**、**无需历史迁移**、**信息待补充**。不能把尚未验证写成完成，也不能把所有待定项都写成用户要求延期。

## A. 用户明确搁置

| ID | 内容 | 当前处理 | 恢复触发 | 后续完成标准 |
| --- | --- | --- | --- | --- |
| D01 | Web 前端的重构、UI/UX、Web Chat / 工作区、浏览器语音、前端 API 类型生成与端到端验收 | 不纳入首轮实现和验收；现有源码暂存，不为首轮新契约维护旧前端兼容 | 用户开启前端提升轮次 | 接入当时的 Server 规范；认证、配置生效、记忆操作、真实投递状态和断线恢复通过；界面完成体验验收 |
| D02 | iOS / Android 前端、原生发现/权限/发布和真机适配 | 不构建、不重构、不作为首轮质量门槛 | 用户开启移动端轮次并指定设备/系统 | 各平台构建、权限/生命周期、发现、认证、网络变化、状态一致性及真机交互通过 |
| D03 | Embedded 通用适配：其他主板、跨 OS、跨 CPU、通用音频/执行器后端矩阵 | 本轮只针对 Pi 5 8 GB 及选定外设；保持边界清晰，但不预先建设通用插件/驱动平台 | Pi 5 首轮稳定后，用户指定第二种硬件或嵌入系统 | 新目标设备独立通过实时音频、动作安全、资源预算、能力与协议测试，并保持 Pi 5 回归通过 |

## C. 首轮候选的接入门槛，不是已决定延期

| ID | 内容 | 启动条件 | 验收/退出条件 |
| --- | --- | --- | --- |
| C01 | Temporal 与独立 Worker | 首轮后台用例明确，规范数据、Outbox、幂等和隐私版本边界已具备 | 杀进程恢复、重复执行、超时取消、历史回放、升级、资源消耗通过；服务异常不阻断实体实时交互。未通过则记录实际后续方案 |
| C02 | Rig Provider、rmcp、Home Assistant 适配 | 对应模型/工具用例进入实施包 | 独立版本与许可核验、行为契约、权限、错误与取消测试；按维护收益和质量决定替换 |
| C03 | Server 非 macOS 平台的完整实机认证 | 有明确目标 OS/架构、runner/实机及依赖条件 | 构建、运行、数据库/模型/协议、安全权限和退出行为验证；无实机证据不得标为正式支持 |
| C04 | 未来设备侧轮次模型/STT 等推理，以及整机同机多进程部署 | 当前用户已明确 Easy-Turn 只运行在 Server，**不评估 Pi 5 承载 Easy-Turn**。指定未来目标设备、模型后端与部署需求后安排实际接入；当前保留模型 endpoint、库入口和传输契约的独立性 | 音频与推理并发时的正确性、尾延迟、内存/散热、取消和回执通过；同机模型/数据库明确各自部署位置；不得复制规范状态所有者 |
| C05 | Server + Device Runtime 单 Rust 进程产品化；进程内传输或自动运行中迁移 | 工程建议后续评估；需明确收益和故障/状态交接要求，三项分别立项 | 启停/全局状态唯一、行为契约一致、资源争用与崩溃影响可接受；动态迁移另验状态交接和旧 epoch 失效 |

Server 可移植性是首轮设计和验证要求，不能整体延期。C03 只区分未指定目标的完整认证与当前可完成的编译/自动测试。测试环境缺失须记录未运行及补齐方式。

C04/C05 不把 Embedded 通用硬件适配加入首轮。库与启动入口分离、模型位置独立、传输契约和单一状态归属是当前架构要求，见[部署设计](plan.md#31-逻辑角色与部署位置分离)；未来部署的实机通过情况仍单独记录。Rust features 是编译能力选择，不代表已经完成这些部署。

Easy-Turn 参考研究、轮次模型选择、AEC、持续采集/播放和自然插话属于首轮主线，不列入延期候选。若接入不达标，需要重新评估路线，不降低已确认的全双工目标。

## F. 后续轮次的接续步骤

1. 阅读本台账、`plan.md` 和届时实际 Git 状态；用户最新决定优先。
2. 用户选定一个或多个 D 项后，明确本轮目标、平台和验收；避免自动把全部搁置项同时启动。
3. 基于届时 Server/Proto 规范复核原设计，先查已实现能力，再决定复用与新增。
4. 为选中项补充实施分工、测试与提交计划，更新状态为“进行中”，保留决策记录。
5. 取得对应验收证据后标为“完成”，记录提交、平台和限制；不能通过删除条目隐藏未完成工作。
